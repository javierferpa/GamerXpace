# GamerXpace

TFG creado con PHP, JavaScript, HTML, CSS y MySQL. Incluye Arkanoid, Space Invaders, perfiles, rankings y un foro.

**Web: [gamerxpace.alwaysdata.net](https://gamerxpace.alwaysdata.net/)**

La aplicación está alojada en **alwaysdata Free, 0 €/mes**, con PHP 8.4, MariaDB, HTTPS y protección WAF. Funciona de forma independiente de ChatGPT. GitHub conserva el código y comprueba su integridad; Pages no ejecuta PHP ni MySQL.

La migración del 14 de octubre de 2026 conserva los **49 archivos originales de `TFG/`** y restaura la copia SQL del **17 de junio de 2021**: 8 usuarios, 4 hilos, 24 mensajes y 23 likes. Las credenciales nuevas están en un archivo privado del servidor, fuera de la raíz web y de Git.

También se añadieron **5 perfiles ficticios, 5 hilos, 22 mensajes y 45 likes** como contenido de ejemplo, con puntuaciones y conversaciones coherentes sobre los juegos. Los datos históricos se conservan y las cuentas temporales de verificación se han retirado.

El plan gratuito requiere acceder periódicamente al panel de alwaysdata: durante el primer año, al menos una vez cada **120 días**, para evitar la suspensión por inactividad. Consulta las [condiciones del proveedor](https://help.alwaysdata.com/en/docs/admin-billing/profile/suspension/).

Consulta la [configuración y mantenimiento](hosting/README.md) y el [registro del despliegue](hosting/DEPLOYMENT.md). La lógica y las limitaciones de seguridad del TFG original se conservan.
